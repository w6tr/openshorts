# Sound library sources

The `.wav` files in this folder are git-ignored (about 48 MB). Each is a short cut
from one of the YouTube videos below, trimmed and resampled to 48 kHz stereo, or a
tone synthesized with ffmpeg. `manifest.json` has the same list as data. Names map
to `{"type": "sfx", "sound": "<name>"}` in `/api/clip/fx`.

Rights: these are clips of other people's uploads, kept locally for the CEO's own
edits. Nothing here grants a licence; check before any use beyond that.
